Interactive Physics — Formula & Lab Guide
1. Sequential Object Naming: Every object gets an exact ID shown in Properties: body[1], body[2], ConstraintForce(3), input[4], measure[6].
2. Force Polar Mode & Equations: Select a Force → open Properties → switch Representation to Polar → enter Input[4] in Magnitude and Input[5]*pi/180 in Direction (rad).
3. Control Text Boxes: Select a Control → open Properties → set Style to Text Box, set Min/Max (e.g., 0 to 360), and type exact angles like 0, 45, 90, 135, 180, 225, 270, 315, 360.
4. Measure Box Work Equation: In Measure Properties, click Y2, label it W, and enter:
|ConstraintForce(3)|*body[1].P.X*cos(Input[5]*pi/180)
5. Pause Control: Open World → Pause Control and add Body[1].P.X>=3 and Body[1].P.X<=-3.
